# Marka ikonları

app-icon-source.png kullanıcı tarafından sağlanan logolar.jpg içindeki kare U ikonunun birebir kırpımıdır (230,240)-(680,690). Yeniden çizim veya üretken görsel değişikliği uygulanmadı.

public/favicon.ico, favicon-32.png, favicon-192.png, apple-touch-icon.png, app-icon-192.png ve app-icon-512.png bu kaynaktan boyutlandırılır. Eski çizim favicon.svg kullanılmaz. Manifest uygulama ikonlarını tanımlar; çevrimdışı çalışma eklenmemiştir.
