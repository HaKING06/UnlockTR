# UnlockTR tanıtım görselleri

| Dosya | Kullanım |
|---|---|
| unlocktr-banner.webp | README ve yatay dijital tanıtım kapağı |
| unlocktr-banner.png | Aynı kapağın PNG paylaşım kopyası |
| unlocktr-poster.webp | Kare sosyal paylaşım afişi, hafif web kopyası |
| unlocktr-poster.png | Kare afişin PNG paylaşım kopyası |

Ölçüler: yatay **2172 × 724**, kare **1254 × 1254** piksel. Metinler Türkçedir; sürüm ve fiyat afişe gömülmediği için kolay eskimez.

Bu görseller Imagegen ile UnlockTR için üretildi; gerçek oyun kapağı veya uygulama ekran görüntüsü değildir. Başka bir oyunun resmi/ortak markalı görseli olarak sunma. Projedeki mevcut lisans notu korunur; bu belge ayrıca yeniden dağıtım hakkı vermez.

Görseller docs altında tutulur, public uygulama bundle'ına eklenmez. README WebP kullanır; PNG kopyası sosyal paylaşım için ayrılmıştır. Ürün hero görseli public/images/unlocktr-world.webp değiştirilmemiştir.
