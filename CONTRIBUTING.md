# Katkı rehberi

Önce README ve LICENSE dosyalarını inceleyin. Küçük ve amaca odaklı değişiklikler yapın; ilgisiz bağımlılık yükseltmelerini aynı değişikliğe eklemeyin.

Frontend için npm test, npm run build ve npm run format:check; backend için npm test çalıştırılır. Önemli arayüz değişikliklerini 390px/768px, klavye ve light/dark tema ile kontrol edin. Gerçek e-posta veya ödeme gönderen testler yazmayın; migration denemelerini izole veritabanında yapın.

Şifre, API anahtarı, kişisel kullanıcı verisi, .env, derleme çıktıları ve yerel çalışma notlarını commit etmeyin. Güvenlik sorunlarını SECURITY.md üzerinden özel olarak bildirin. Değişikliğin amacını, doğrulamasını ve bilinen sınırlarını açıklayın. Mevcut lisans otomatik yeniden dağıtım hakkı sağlamaz.
